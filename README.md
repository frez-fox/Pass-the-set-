# PassTheSet

Render-ready Node.js multiplayer game.

## Structure

PassTheSet/
├── server.js
├── package.json
└── public/
    └── index.html

## Run locally

Node.js 18+:
npm install
npm start

Then open http://localhost:3000

## Render

Build Command: npm install
Start Command: npm start

The server automatically uses Render's PORT environment variable.
